# Terminal App

A terminal emulator for Android with Material 3 design.

## Features

- Material 3 dark theme
- Terminal emulation with command execution
- Settings with wake lock, temperature limit, memory/storage limits
- .zip file loading and extraction
- Bottom navigation bar

## Building

The app is built using GitHub Actions CI. Push to the repository to trigger a build.

## Permissions

- Internet access
- Storage access
- Wake lock
- Foreground service
